## 许可证说明

- **MIT、Apache 2.0**：可以自由使用、修改、商用，保留原作者的版权声明即可。
- **GPL 3.0（ComfyUI）、AGPL 3.0（VoiceStudio）**：修改后再发布，必须用同样的许可证公开源码；AGPL 连“作为网络服务提供给别人用”也算发布。
- **Elastic 2.0（context-mode）**：可以看源码、自己用，但不能拿来做成托管服务卖给别人，严格来说不算开源许可证。
- **未注明（cursor/plugins）**：仓库根目录没有许可证文件，默认保留所有权利，使用前请看具体插件目录里的说明。
