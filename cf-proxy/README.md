# 复习本反向代理（Cloudflare Workers）

`worker.js` 把 GitHub Pages 上的复习本（`https://cccc65522.github.io/claude-code/`）反向代理到你自己的地址下，适合在 github.io 打不开或很慢的时候用。

- 只转发 GET 和 HEAD 请求（这是静态网站，用不到别的请求）。
- 不会把访问者的 Cookie 转发给上游。
- GitHub 返回的重定向会改写回你自己的域名，浏览器不会跳回 github.io。
- 在 Cloudflare 边缘缓存 5 分钟；网站自己的离线缓存是“先联网”，所以更新几分钟内就能看到。

## 部署步骤（免费）

1. 注册并登录 [Cloudflare](https://dash.cloudflare.com/)。
2. 左侧菜单进入 **Workers 和 Pages**，点 **创建**，选 **创建 Worker**，起个名字（比如 `fuxi`），点 **部署**。
3. 部署完成后点 **编辑代码**，把编辑器里原有的代码全部删掉，粘贴 `worker.js` 的全部内容，再点 **部署**。
4. 打开 Cloudflare 分配的地址 `https://fuxi.<你的子域>.workers.dev` 测试，能看到复习本首页就成功了。

## 绑定自己的域名（国内访问建议做这一步）

`workers.dev` 这个域名在中国大陆经常打不开，想在国内稳定访问，最好绑定一个自己的域名：

1. 买一个域名（一年几十元），把它的 DNS 托管到 Cloudflare（在 Cloudflare 里“添加站点”，按提示去域名注册商那里修改 NS 记录）。
2. 回到 Worker 的 **设置 → 域和路由 → 添加 → 自定义域**，填一个子域名，比如 `fuxi.你的域名.com`。
3. 等几分钟证书签发完成，就能用 `https://fuxi.你的域名.com` 打开了。

说明：Cloudflare 在大陆没有节点，速度比不上备案后的国内服务器，但通常比直接访问 github.io 稳定。真正要在国内又快又稳，需要做 ICP 备案，再放到国内的云存储上。

## 可选配置

在 Worker 的 **设置 → 变量** 里可以覆盖默认值，不用改代码：

| 变量 | 默认值 | 作用 |
| --- | --- | --- |
| `UPSTREAM` | `https://cccc65522.github.io` | 被代理的源站 |
| `BASE_PATH` | `/claude-code` | 网站在源站上的路径 |

## 注意：换地址后数据不会自动过去

复习本的题库和做题记录存在浏览器里，而且是按网址分开存的。从 github.io 换到新地址以后，新地址上一开始是空的。换之前，在旧地址的“数据”页**导出备份**，到新地址的“数据”页**恢复**。
