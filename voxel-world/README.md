# 方块小镇：React + three.js 的 3D 方块世界

一个原创的第一人称方块世界：随机生成有平原、森林、沙漠、雪原四种生物群系，还有湖、雪山和地下洞穴的地形，有昼夜循环、会发光的火把和会流动的水，可以挖方块、放方块、合成、种地、养动物、睡觉、用箱子存东西、游泳、飞行，改动自动保存在浏览器里。分生存模式（有生命值、饥饿、摔落伤害、溺水和夜里出没的怪物，挖到的东西进背包，放方块要消耗，靠合成做出新东西）和创造模式（方块无限、不会受伤）。电脑用键盘鼠标，手机用触屏摇杆。

## 运行

需要 Node.js 20 或更新版本。

```bash
cd voxel-world
npm install
npm run dev       # 开发模式，打开终端里显示的地址
npm run build     # 打包到 dist/，可以放到任何静态网站托管上
npm run preview   # 本地预览打包结果
npm test          # 单元测试（地形、网格、射线、碰撞）
```

## 世界大小

世界是 256×256 格（16×16 个区块），高 48 格，四周是看不见的墙。为了打开得快：新世界的地形、洞穴和光照大约 0.2 秒算完；一开始只建玩家身边 5×5 个区块的网格，剩下的在游戏里每帧由近到远补一些（每帧最多约 6 毫秒），远处在雾里慢慢出现；离玩家 120 格以外的区块不画。改一个方块时，火把光和天光都只重算附近 15 格。

## 生物群系

按“温度”和“湿度”两张大尺度的噪声图分成四种（左上角会显示你在哪种群系里）。地形的高低所有群系都一样，所以边界上不会突然出现断崖，不同的是地面、植物和水面：

| | 平原 | 森林 | 沙漠 | 雪原 |
| --- | --- | --- | --- | --- |
| 地面 | 草地 | 草地 | 厚厚的沙子，下面几层是**砂岩** | 雪（岸边也是） |
| 植物 | 零星的树 | 很密的树 | **仙人掌**（1–3 格高） | 尖尖的**雪松** |
| 水面 | 水 | 水 | 水 | 结成**冰** |
| 动物 | 兔子、鸭子、野猪 | 野猪多 | 没有 | 兔子 |

- **仙人掌**：碰到会被扎（生存模式每半秒扣半颗心）；只能长在沙子上，底下的沙子没了整根倒下（都能捡回来）；夜影不会生在仙人掌上。
- **冰**：上面很滑，走起来、停下来都慢；用镐挖开以后变回水（不掉东西）。
- **砂岩**：沙漠里挖得到，也可以用沙子 ×4 合成，适合盖房子。

## 天气

- 晴天（现实 5–10 分钟）和下雨（1.5–3 分钟）轮流来，开始和结束都是慢慢变化的。
- 平原和森林下雨（一道道浅蓝的雨线），雪原下雪（慢慢飘的雪花），沙漠不下，只是阴天。
- 下雨时天空变灰、阳光变弱、雾变近，太阳、月亮和星星被遮住；有循环的雨声，在屋檐下、屋里、洞里小一些。雨和雪落到每一列最高的方块就停，所以屋顶下面淋不到。
- 露天的庄稼淋到雨，和旁边有水一样长得快。
- 暂停菜单里可以把天气切到“晴”或“下雨”。天气会存档。

## 地图

- **小地图**：右上角显示玩家周围 64×64 格，北（-z）在上；白色箭头是你和你面朝的方向，红点是你的床（重生点）。暂停菜单里可以隐藏。
- **大地图**：按 `M`（手机点“地图”）看整个世界，还会显示探索了百分之多少。
- 颜色按每一列最上面的方块：草地绿、沙子黄、雪白、石头灰、树冠深绿，水是蓝的而且越深越暗；再按和西北边的高低差加一点明暗，看得出山坡。
- **只显示去过的地方**：玩家周围 40 格以内会被“点亮”，没去过的是空白。探索记录每格一位、打包成大约 11 KB 的字符串存在存档里。改了方块、庄稼长了、水流过，地图都会跟着更新。

暂停面板里可以切换生存 / 创造模式，“重置世界”（同时清空背包）（回到刚生成的样子）、“新世界”（换一个随机种子），也可以直接跳到“白天”或“夜晚”。

## 生存模式和合成

新世界默认是生存模式，背包是空的；加合成之前的老存档会保持创造模式，可以随时在暂停菜单里切换，背包会保留。

- **生命值**：快捷栏上方 10 颗心（20 点）。从 4 格以上的地方摔下来会掉血，每多 1 格扣 1 点（半颗心），屏幕边缘会闪红；掉进水里、飞着下降不会摔伤。6 秒没受伤后每 2.5 秒回 1 点。血量很低时心会跳动。生命值归零会显示死因，点“重生”回到出生点、满血，背包保留。
- **饥饿**：快捷栏上方右边 10 个鸡腿（饱食度 20 点）。闲着大约半小时饿掉一半；跑步、跳、游泳、挖方块、打怪、回血都会饿得更快。饱食度至少 7 个鸡腿才会回血；饿到 0 以后每 4 秒掉半颗心，可能饿死。饱食度降到 3 个鸡腿时会提醒。
- **食物**：砍树叶有 10% 几率掉**苹果**（+2 鸡腿），挖草方块有 15% 几率挖到**野莓**（+1），自己种的小麦做**面包**（+3），**生肉**（+1）/ **烤肉**（+4），**蛋饼**（+3），用苹果 ×2 + 野莓 ×3 + 煤炭 ×1 合成**果派**（+5）。按 `R`（手机点右上角“吃”）自动挑一样吃，尽量不浪费；也可以在背包的“食物”一栏点“吃”。和平模式下不会饿，还会慢慢吃饱。
- **耕种**：挖草方块有 25% 几率挖到**麦种**。选麦种对着草地、泥土右键：背包里有**石锄**（石头 ×2 + 木棍 ×2）就会先把它翻成**耕地**再种下（创造模式不需要锄头）。小麦分 4 个阶段，每秒有一定几率长一阶：耕地 4 格内有水时平均约 36 秒成熟，干地约 90 秒（所以可以用水桶在田边挖条水沟）。收割（一碰就掉）成熟的小麦得到**小麦** ×1 和麦种 1–2 颗，没熟的只退回麦种。耕地被挖掉、水流过都会毁掉上面的庄稼。小麦 ×3 合成**面包**（+3 鸡腿）。
- **动物**（都是原创设计，两种模式都有）：白天在各自住的地方出现（48 格内野生的不够 10 只时才会冒新的，整个世界最多 40 只，生小动物也算在内）。

  | | 绒耳兔 | 鬃毛野猪 | 圆圆鸭 |
  | --- | --- | --- | --- |
  | 样子 | 奶油色，长耳朵，白尾巴 | 深棕色，背上一道鬃毛，猪鼻子和白獠牙 | 奶白色圆身体，绿头，橙色扁嘴和脚掌 |
  | 住在 | 草地 | 树林边的草地（5 格内有树干） | 水边的沙地或草地（5 格内有水） |
  | 走路 | 一跳一跳 | 走路，碰到一格高的台阶会跳上去 | 走路，会游泳（浮在水上） |
  | 爱吃 | 麦种 | 苹果 | 野莓 |
  | 被打后 | 逃跑 | **冲过来撞人**（每下扣 1 颗心并撞开，追 8 秒）；和平或创造模式下逃跑 | 逃跑 |
  | 血量 / 掉落 | 6 / 生肉 1–2 | 12 / 生肉 2–3 | 4 / 生肉 1 |
  | 特别 | | | 长大后每 1.5–2.5 分钟在脚下下一个**鸭蛋**（地上的小蛋，一碰就捡起来） |

  **对着动物右键就是喂它**（不用选哪一格，自动用背包里它爱吃的；创造模式不消耗），头上冒出红心；两只喂过的同种动物靠在 3 格内会**生一只小的**（小一号，一分钟后长大；生过的要等一分钟才能再喂）。**选着麦种那一格时**，8 格内、背包里有它爱吃的东西的动物会跟过来。小动物打死不掉东西。生肉 ×2 + 煤炭 ×1 烤成**烤肉** ×2，鸭蛋 ×2 + 小麦 ×1 + 煤炭 ×1 做成**蛋饼** ×2。**动物会存档**（位置、朝向、血量、种类、小的还要多久长大、繁殖冷却），离得再远也不会消失，只有被打死才没了；夜影不存档。
- **床**（木板 ×3 + 树叶 ×4）：矮矮的一格。对着它右键：**晚上**就睡一觉，画面变黑再亮，直接到早上；附近 8 格有夜影时睡不着；白天睡不着。不管睡没睡着，这张床都会成为**重生点**：死了以后在床上醒来；床被挖掉的话会提示并回到出生点。
- **箱子**（木板 ×8）：对着它右键打开，上面是箱子里的东西（“取 1”“全部”），下面是背包（“存 1”“全部”）。箱子里的东西会存档；挖掉箱子时，里面的东西会自动放进背包。
- **门**（木板 ×6）：两格高，放下时门板朝着你面对的方向。对着门（上半下半都行）右键开关：关着的门挡得住玩家、夜影和动物，开着就转到旁边、能走过去；站在门口时关不上。拆掉一半另一半也没了（只掉一扇门），脚下的方块挖掉门也会掉。
- **梯子**（木棍 ×7 → 3 个）：贴在墙的侧面（点墙的侧面放）。站在梯子上往前走或按跳就往上爬，按 `C` 往下，不按就慢慢滑下来；在梯子上不会摔伤。墙被挖掉，贴在上面的梯子会掉。
- 因为没了支撑而掉下来的东西（火把、庄稼、鸭蛋、门、梯子）都会自动捡回背包。
- **溺水**：头没入水中时，生命值上方出现 10 个气泡，大约 15 秒用完，之后每秒扣 1 颗心；浮出水面后 2 秒内回满。
- **夜影**（怪物）：原创的深紫色方块小怪，有两只发黄光的眼睛。只在夜里、离玩家 16–30 格、火把照不到的黑暗地面上出现，最多 8 只；一跳一跳地追过来，咬一口扣 1.5 颗心并把人撞开。左键打它（准星对着，按住可以连打）：空手 2 点，有石镐 3、石斧 4、铁镐 5（自动用最好的），10 点血，打死有一半几率掉煤炭。天亮后会慢慢消散。**在家周围插火把就不会有夜影冒出来。**创造模式没有怪物。
- **和平开关**：暂停菜单里“怪物”一栏选“和平”，就不会再出现夜影，已经出现的也会立刻消失，也不会饿；摔落和溺水照样会受伤。这是玩家设置，存在 `voxel-world:peaceful` 里，换新世界、重置世界都会保留。
- **挖**：要按住，准星周围的圆环和方块变暗表示进度，挖到的方块进背包。空手挖泥土、沙子约半秒，木头约 1.5 秒，石头约 2 秒。草方块和雪地挖出来是泥土，基岩挖不动，水挖不到。地下的石头里夹着**煤矿石**（挖出来是煤炭），更深的地方有**铁矿石**（必须用镐挖）。
- **工具**：镐、铲、斧不用拿在手上，挖方块时自动用背包里最合适的一把：镐挖石头和矿石、铲挖泥土和沙子、斧砍木头和树叶，石制工具快 4 倍，铁镐快 8 倍。工具不会坏，每种只需要做一把。
- **水桶**：空桶对着水源（不流动的水）装水，水桶把一格水源倒到别处，倒完变回空桶。流动的水装不了。
- **放**：快捷栏 12 格（泥土、石头、沙子、原木、木板、树叶、玻璃、砖块、火把、空桶、水桶、麦种）显示数量，用完的格子变灰，没有了就放不了。
- **合成**（不用摆位置，材料够就能做，“全部”一次做到材料用完）：

| 材料 | 得到 |
| --- | --- |
| 原木 ×1 | 木板 ×4 |
| 木板 ×2 | 木棍 ×4 |
| 木棍 ×1 + 煤炭 ×1 | 火把 ×4 |
| 沙子 ×2 + 煤炭 ×1 | 玻璃 ×2 |
| 泥土 ×2 + 沙子 ×1 + 煤炭 ×1 | 砖块 ×2 |
| 石头 ×3 + 木棍 ×2 | 石镐 |
| 石头 ×1 + 木棍 ×2 | 石铲 |
| 石头 ×3 + 木棍 ×2 | 石斧 |
| 铁矿石 ×1 + 煤炭 ×1 | 铁锭 ×1 |
| 铁锭 ×3 + 木棍 ×2 | 铁镐 |
| 铁锭 ×3 | 空桶 |
| 苹果 ×2 + 野莓 ×3 + 煤炭 ×1 | 果派 ×1 |
| 石头 ×2 + 木棍 ×2 | 石锄 |
| 小麦 ×3 | 面包 ×1 |
| 生肉 ×2 + 煤炭 ×1 | 烤肉 ×2 |
| 鸭蛋 ×2 + 小麦 ×1 + 煤炭 ×1 | 蛋饼 ×2 |
| 木板 ×3 + 树叶 ×4 | 床 |
| 木板 ×8 | 箱子 |
| 木板 ×6 | 门 |
| 木棍 ×7 | 梯子 ×3 |
| 沙子 ×4 | 砂岩 |

大致的顺序是：砍树拿原木 → 做木板、木棍 → 挖石头做石镐 → 往下挖找煤矿石做火把 → 再往深处用镐挖铁矿石，炼成铁锭做铁镐和水桶。

## 音效

所有声音都是用 Web Audio 当场合成的（滤过的噪声加振荡器），没有音频文件。声音有远近（24 格外听不见）和左右声道。

- **方块**：挖掉、放下、踩上去都按材质发声：石头清脆、泥土和草闷闷的、沙子沙沙、雪软软的、木头咚咚、树叶和庄稼窸窣、玻璃碎掉叮叮当当。生存模式按住挖时会一下下地敲。
- **玩家**：脚步（跑步步子大）、从高处落地、掉进水里、游泳划水、受伤、吃东西、合成、睡觉、水桶装水倒水。
- **生物**：夜影离得近时会低沉地咕噜，被打和消散也有声音；绒耳兔被打会吱吱叫；鬃毛野猪时不时哼哼；圆圆鸭时不时嘎嘎叫，下蛋时“啵”一声。
- **音量**：暂停菜单里有音量滑条和静音按钮，是玩家设置（存在 `voxel-world:volume`），换世界也保留。浏览器要求点过“开始”之后才能出声。

## 洞穴和天光

- **洞穴**：生成世界时有几十条弯弯曲曲的隧道在地下钻过，碰到地面附近就成了洞口。煤矿石和铁矿石会露在洞壁上。湖底、海底下面留着不挖穿，水不会漏进洞里。
- **天光**：每一格都有一个“能看到多少天”的值（0–15）：露天是 15，往下被不透明的方块挡住就没了，往旁边每走一格减 1（树叶、玻璃挡一点点，水不挡）。日光和月光照明会乘上天光，所以**洞穴深处、封死的屋子里是黑的**，悬崖下、棚子下面暗一些；火把的光单独算，照到的地方白天黑夜都亮。夜影和动物的身体也会按所在位置的明暗变暗。
- **洞里的夜影**：洞里足够黑（天光低于 4）的话，**白天也会出现夜影**，但只在玩家上下 12 格内的洞里生成；它们只有晒到太阳（天光 8 以上）才会消散，所以在洞里不会自己消失。往洞里走记得带火把。

## 水和昼夜

- **水**：低于海平面的地方会生成湖和小海湾。水是半透明的，可以穿过、游泳；准星会穿过水对准水底，所以能隔着水挖、往水里放方块（会把那格水换掉）。快捷栏最后一格（`-`）是水源，可以自己放。
- **流动的水**：每 0.25 秒流一格。水先往下流，流不下去才往四周散开，平地上最多流 7 格、越远越浅；从高处落下的水落地后重新散开。挖开湖岸，湖水会流出来；挖掉或堵住水源，流水会一格格退掉。两个水源中间托得住的空格会变成新的水源。水会冲掉火把。
- **火把**（`0`）：只能立在实心方块上，脚下方块挖掉就会掉。火光会一格格往外扩散、越远越暗，墙会挡光，水、玻璃、树叶不挡；晚上能照亮周围，火光会轻轻闪烁。
- **水下**：眼睛进水后画面变蓝、能见度变低。
- **昼夜**：现实 12 分钟是游戏里一整天。有太阳、月亮、星星，日出日落时天边发红，晚上光线变暗、变成蓝白色的月光。左上角显示游戏时间，时间也会存档。

## 方块

草方块、泥土、石头、沙子、原木、木板、树叶、玻璃、砖块、火把、水可以放置；地形里还有雪地，最底层是挖不掉的基岩。所有贴图都是 `src/game/atlas.js` 在运行时逐像素画出来的，没有图片文件。

## 代码结构

```
src/
  game/                 纯 JS，不依赖 React，可以单独测试
    blocks.js           方块种类、贴图编号、快捷栏
    noise.js            可复现的随机数和值噪声
    world.js            256×48×256 的世界数据、地形、洞穴、湖、树（雪松、仙人掌）的生成、玩家改动记录
    biomes.js           生物群系：按温度和湿度分成平原、森林、沙漠、雪原
    weather.js          天气：晴雨交替、强度渐变、各群系下雨还是下雪、有没有遮挡
    mesher.js           把一个 16×16 区块转成顶点数据：只画露在外面的面，带环境光遮蔽；水单独一份网格
    daynight.js         昼夜循环：太阳位置、天空颜色、光照强度、星星
    light.js            火把光照（从火把逐格扩散）和天光（从天上往下、再往旁边扩散）；改方块时两种光都只重算附近 15 格
    fluid.js            流动的水：水位规则和逐步模拟
    sim.js              把改方块、火把掉落、水流、重算光照串起来，算出要重建哪些区块
    items.js            物品（方块 + 木棍、煤炭、工具、桶、食物）、挖方块的掉落、背包加减、吃东西
    crafting.js         合成配方
    tools.js            挖方块的时间、工具种类和速度
    health.js           生命值、摔落伤害、回血、溺水、饥饿
    monsters.js         夜影：生成条件、跳跃追击、咬人、被打、消散
    farming.js          耕种：翻土种地、湿润判断、生长、收割
    home.js             床（睡觉、重生点）、箱子（存取、存档）、快捷栏自选格
    building.js         门和梯子：放置、朝向、开关、门板和梯子在格子里的位置
    map.js              地图：每列的颜色和明暗、探索记录（打包存档）
    sound.js            音效：材质分类、远近和左右声道、脚步节奏，以及用 Web Audio 合成各种声音
    animals.js          动物（绒耳兔、鬃毛野猪、圆圆鸭）：住的地方、生成、闲逛、跟随、喂食繁殖、逃跑或反击、下蛋、掉落、存档
    raycast.js          逐格射线检测，找准星对着的方块和面
    player.js           碰撞盒物理（玩家和怪物共用）、重力、跳跃、游泳、飞行、记录摔落高度
    atlas.js            生成像素贴图图集（需要浏览器 canvas）
    renderer.js         每个区块一个实心 Mesh 加一个半透明水 Mesh：开始时只建身边的，其余每帧由近到远补齐；太远的不画；只重建有变化的区块
  components/
    Game.jsx            react-three-fiber 场景：怪物和动物模型、雨雪粒子、天空、日月星、光照（材质里加了天光和火把光）、雾、云、水下效果，每帧的移动、挖放和水流
    Hud.jsx             准星、坐标、生命值、饱食度、氧气、快捷栏（生存模式显示数量）
    Inventory.jsx       背包、食物和合成面板；创造模式的方块选择器
    Chest.jsx           箱子面板
    MapView.jsx         小地图和大地图
    TouchControls.jsx   手机摇杆和按钮
  App.jsx               输入处理、模式切换、开始/暂停面板、自动保存
```

开发服务器（`npm run dev`）里可以在控制台用 `window.__voxel.session` 查看和修改当前世界、玩家、背包、怪物、动物和庄稼，`window.__voxel.renderer.rebuildKeys(...)` 手动重建区块；打包后的版本没有这个入口。

存档放在 `localStorage` 的 `voxel-world:v1` 里，只记种子、改过的方块、位置、重生点、生命值、饱食度、时间、天气、模式、背包、快捷栏自选格、箱子里的东西、动物和探索过的地方，所以很小。隐私模式下存不了也照样能玩。
