# 方块小镇：React + three.js 的 3D 方块世界

一个原创的第一人称方块世界：随机生成带湖、树和雪山的地形，有昼夜循环，可以挖方块、放方块、游泳、飞行，改动自动保存在浏览器里。电脑用键盘鼠标，手机用触屏摇杆。

## 运行

需要 Node.js 20 或更新版本。

```bash
cd voxel-world
npm install
npm run dev       # 开发模式，打开终端里显示的地址
npm run build     # 打包到 dist/，可以放到任何静态网站托管上
npm run preview   # 本地预览打包结果
npm test          # 单元测试（地形、网格、射线、碰撞）
```

## 操作

| | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | `W` `A` `S` `D`（`Shift` 跑） | 左下角摇杆，推到底会跑 |
| 视角 | 鼠标（点“开始”后锁定鼠标） | 在屏幕上拖动 |
| 跳 | `空格` | “跳”按钮 |
| 挖 / 放 | 左键 / 右键，按住连续 | “挖” / “放”按钮，按住连续 |
| 选方块 | `1`–`9`、`0` 或滚轮 | 点底部快捷栏 |
| 游泳 | 水里 `空格` 上游、`C` 下潜，贴着岸按 `空格` 上岸 | 水里按“跳”上游、贴着岸按“跳”上岸 |
| 飞行 | `F`；`空格` 上升、`C` 下降，落地自动停 | 右上角“飞行” |
| 暂停 | `Esc` | 右上角“暂停” |

暂停面板里可以“重置世界”（回到刚生成的样子）、“新世界”（换一个随机种子），也可以直接跳到“白天”或“夜晚”。

## 水和昼夜

- **水**：低于海平面的地方会生成湖和小海湾。水是半透明的，可以穿过、游泳；准星会穿过水对准水底，所以能隔着水挖、往水里放方块（会把那格水换掉）。快捷栏第 10 格是水，可以自己放。水是静止的，不会流动。
- **水下**：眼睛进水后画面变蓝、能见度变低。
- **昼夜**：现实 12 分钟是游戏里一整天。有太阳、月亮、星星，日出日落时天边发红，晚上光线变暗、变成蓝白色的月光。左上角显示游戏时间，时间也会存档。

## 方块

草方块、泥土、石头、沙子、原木、木板、树叶、玻璃、砖块、水可以放置；地形里还有雪地，最底层是挖不掉的基岩。所有贴图都是 `src/game/atlas.js` 在运行时逐像素画出来的，没有图片文件。

## 代码结构

```
src/
  game/                 纯 JS，不依赖 React，可以单独测试
    blocks.js           方块种类、贴图编号、快捷栏
    noise.js            可复现的随机数和值噪声
    world.js            128×48×128 的世界数据、地形、湖和树的生成、玩家改动记录
    mesher.js           把一个 16×16 区块转成顶点数据：只画露在外面的面，带环境光遮蔽；水单独一份网格
    daynight.js         昼夜循环：太阳位置、天空颜色、光照强度、星星
    raycast.js          逐格射线检测，找准星对着的方块和面
    player.js           玩家碰撞盒、重力、跳跃、游泳、飞行
    atlas.js            生成像素贴图图集（需要浏览器 canvas）
    renderer.js         每个区块一个实心 Mesh 加一个半透明水 Mesh，改方块时只重建受影响的区块
  components/
    Game.jsx            react-three-fiber 场景：天空、日月星、光照、雾、云、水下效果，每帧的移动和挖放逻辑
    Hud.jsx             准星、坐标、快捷栏
    TouchControls.jsx   手机摇杆和按钮
  App.jsx               输入处理、开始/暂停面板、自动保存
```

存档放在 `localStorage` 的 `voxel-world:v1` 里，只记种子、改过的方块、位置和时间，所以很小。隐私模式下存不了也照样能玩。
