# 造物：二维物理沙盒

在浏览器里随手画东西，它们就会掉下来、滚起来、撞在一起。可以用钉子、马达、弹簧、绳子把东西连成小车、投石机、吊桥，也可以闯关。电脑和 iPhone 上都能用。

物理引擎是从零写的，没有用任何第三方库：碰撞检测、约束求解、关节、休眠都是自己实现的。

## 功能

| 功能 | 说明 |
| --- | --- |
| 画图造物 | **画笔**随手画：首尾相接是实心形状（凹的也行），不闭合是一根有粗细的线；**方块**拖出矩形；**圆**从圆心往外拖。点一下直接放一个 1 米的方块或球。 |
| 材料 | 木头、金属、橡胶、冰、石头、气球。密度、摩擦、弹性各不相同：冰很滑，橡胶很弹，金属很重，气球会往上飘。也可以把画的东西“固定”在原地当地形。 |
| 连接 | **钉子**把两个重叠的物体钉在一起（能转动），只点一个物体就钉在背景上；**马达**是会一直转的钉子，可以调转速、力度、方向；**粘合**把两个物体粘成一体；**弹簧**可以调硬度、阻尼、长度；**绳子**由一节节绳段连成，能吊、能拉，用橡皮可以剪断。 |
| 玩 | 运行时用**拖动**工具抓住物体甩出去；**爆炸**把周围的东西炸开；单步、慢动作（四分之一速度）；**时光倒流**：暂停后拖动进度条回到过去任意时刻，再从那里接着播放。 |
| 编辑 | 撤销 / 重做（所有修改）；“重置”回到按播放之前；暂停时拖动物体会连着钉在一起的物体一起移动；选中物体可以换材料、旋转、复制、删除。 |
| 演示 | 拆楼（铁球荡下来撞 78 块积木）、多米诺（每块比前一块大 15%）、小车、跷跷板投石、吊桥、谐波摆（12 个单摆 40 秒后重新对齐）、滚楼梯（布娃娃）、高尔顿板（300 颗球堆出正态分布）、气球、搅拌机。 |
| 闯关 | 9 个原创关卡：把红色小球送进绿色星星框并停够 1 秒。每关限定能用的工具和数量，斜线区域不能画。搭桥、刹车（得选对材料）、跷跷板、多米诺、升空（气球加绳子）、钉住、造车（马达）、蹦床（弹簧）、摆锤。卡住了可以看参考答案。 |
| 保存与分享 | 画布自动保存在本机；可以存成“我的作品”；**分享链接**把整个场景压缩编码进网址（演示场景的链接 500–3700 个字符），不经过任何服务器，对方打开就是同一个场景；也可以导出 / 导入 JSON 文件。 |
| 其他 | 碰撞音效（按材料和撞击速度实时合成）；iPhone 上可以开“重力跟着手机倾斜”；“显示引擎内部”可以看凸分解后的碰撞形状、粗检测树的包围盒、接触点和法线、每步耗时；深色模式；可以“添加到主屏幕”离线使用。 |

## 运行方法

需要 Node.js 18 或更新版本。运行网站本身不需要安装任何依赖。

```bash
cd physics
npm start            # 等同于 node scripts/serve.js，默认端口 8080
```

电脑上打开 <http://localhost:8080>；iPhone 连同一个 Wi-Fi 时用 Safari 打开启动日志里的局域网地址。也可以把 `physics/` 目录原样放到任何 HTTPS 静态托管上（比如 GitHub Pages），重力感应和离线使用需要 HTTPS。

地址参数：`?blank` 空白画布，`?demo=galton` 打开某个演示，`?level=car` 直接进某一关，`?fresh` 不读取上次保存的画布。

> 直接双击 `index.html`（`file://`）打不开，浏览器不允许这样加载 ES 模块。

## 引擎是怎么工作的

每一步（1/60 秒）：更新接触（窄检测）→ 求解 → 同步形状 → 找新的碰撞对（粗检测）→ 让静止的物体休眠。

**粗检测**（`js/engine/tree.js`）：动态 AABB 树。每个碰撞形状的包围盒放大一圈（再按运动方向多放一些）存进一棵平衡的包围盒层次树，物体动得不多就不用重新插入；插入时按表面积启发式选位置，用 AVL 旋转保持平衡。只有包围盒重叠的形状对才进入下一步。

**窄检测**（`js/engine/collide.js`）：圆和凸多边形（最多 8 个顶点）。多边形之间用分离轴定理找最小穿透的边，再把对面的边裁剪到参考边的范围内，得到最多两个接触点；每个点带特征编号，下一步能对上号，沿用上一步算出的冲量（热启动）。接触点在两物体相距一小段距离时就生成了（预测接触），快速运动的物体这段距离会按速度放大，所以不会一步穿过薄墙。

**求解器**（`js/engine/world.js`、`js/engine/joints.js`）：软约束子步求解（soft step，Box2D v3 的思路）。每一步分成 4 个子步：积分速度 → 用累计冲量热启动 → 把接触和关节当作刚度很高、阻尼很大的弹簧来解（隐式解，任何刚度下都稳定，穿透是被平滑地推开而不是弹开）→ 积分位置 → 不带位置修正再“松弛”解一遍，去掉多余的能量。弹性碰撞在所有子步之后单独处理。另外有摩擦、圆的滚动阻力、速度上限。

**关节**：铰链（马达、角度限制）、距离（刚性连杆、弹簧、只限最大长度的绳长）、焊接、鼠标拖拽。绳子是一串铰链连起来的绳段，再加一条首尾之间的最大长度约束——否则很轻的绳段吊很重的东西时会被拉长，有了它，吊起比单节绳段重 1500 倍的东西也只伸长不到 1%。

**休眠**：物体以“岛”（通过接触和关节连在一起的一组物体）为单位，整组都静止半秒后一起休眠，不再参与计算；被碰到、被删掉支撑、被拖动时整组唤醒。

**画图**（`js/engine/geometry.js`）：笔画先用 Ramer–Douglas–Peucker 算法简化。闭合的笔画如果是凹多边形，用耳切法三角化（每次切形状最好的那只“耳朵”，避免细长三角形），再用 Hertel–Mehlhorn 算法把三角形合并回最多 8 个顶点的凸块；笔画自相交时退回到凸包。不闭合的笔画变成一串带圆角的长条。

**确定性**（`js/engine/math.js`）：JavaScript 里的 `Math.sin`、`Math.cos`、`Math.atan2` 由各浏览器自己实现，最后一位可能不一样，物理模拟会把这一点差别越放越大。引擎只用规范规定了精确结果的运算（加减乘除、`Math.sqrt`、`Math.round`），三角函数用自己写的多项式（fdlibm 的系数）。所以同一个场景在任何浏览器、任何设备上模拟的结果逐位相同。关卡每次开始时都先把场景存成 JSON 再重建，一次运行只取决于这份 JSON。

在开发机的 Node.js 里：20 层 210 块的金字塔稳稳站住，约 1 秒后整体休眠；600 个方块和圆同时落进箱子里堆起来，平均每步约 2 毫秒；搅拌机（150 个物体一直在动）每步约 0.4 毫秒。

## 代码结构

```
index.html, css/app.css, manifest.webmanifest, sw.js, icons/
js/
  engine/                不依赖 DOM，Node 里也能跑
    math.js              确定性的三角函数、软约束系数、随机数
    shapes.js            圆、凸多边形、凸包、质量与转动惯量
    tree.js              动态 AABB 树
    collide.js           接触点生成
    joints.js            铰链（马达、限位）、距离（弹簧、绳长）、焊接、拖拽
    world.js             物体、接触、子步求解器、休眠、查询、爆炸
    geometry.js          笔画简化、耳切三角化、凸分解
    scene.js             场景 JSON 与世界之间的转换
    build.js             生成场景的工具、绳子
    materials.js         材料
    recorder.js          时光倒流的录像
    demos.js             演示场景
    levels.js            关卡和参考答案
    level-run.js         关卡判定、限制和摆放规则
  ui/
    renderer.js          Canvas 绘制（按轮廓画，不画凸分解后的碎块）、特效、引擎内部视图
    camera.js, input.js  视图变换；鼠标、触摸、双指缩放、滚轮
    tools.js             各个工具
    sound.js             Web Audio 合成音效
    share.js             链接编码（deflate + base64url）
    ui.js, icons.js, storage.js
  app.js                 播放、撤销、重置、倒流、关卡流程、对话框、保存
scripts/serve.js         零依赖静态服务器
tests/unit/              Node 自带测试运行器
tests/e2e/               Playwright 端到端测试（电脑 + iPhone 13 尺寸）
```

## 测试

```bash
cd physics
npm test                 # 单元测试，约 2 秒，无需安装依赖
npm install              # 只有端到端测试需要
npm run test:e2e
```

单元测试（69 个）：

- 引擎：三角函数与 `Math.sin/cos` 的误差；质量和转动惯量（平行轴定理）；AABB 树在 2000 次随机插入、移动、删除后结构仍然正确、查询结果和暴力枚举一致；接触点和法线；自由落体；箱子落地后不抖、穿透不超过 1 厘米并休眠；210 块金字塔 8 秒内偏移小于 5 厘米且全部休眠；斜坡上的静摩擦和冰面上的滑动加速度；橡胶球反弹高度约为 e² 倍；单摆周期与 2π√(L/g) 相差不到 1%、25 秒后振幅还保持 97%；马达转速；铰链限位；链条和绳子的伸长；焊接后保持刚性；弹簧振动频率；80 米/秒的球打不穿 10 厘米的墙；休眠与唤醒；同样的输入两次模拟逐位相同；爆炸。
- 画图：L 形、U 形、星形、圆形以及 300 个随机简单多边形的凸分解——每块都是凸的、不超过 8 个顶点、面积之和等于原图形；自相交判断；笔画分类；场景 JSON 存取往返不变；从 JSON 重建后模拟逐位相同。
- 关卡：每一关的参考答案都能过关，什么都不画则过不了；把答案整体挪动 5 厘米（4 个方向）仍然能过关，不是碰巧；答案遵守这一关的工具、数量和禁画区规则；运行可复现；10 个演示都能实时运行且数值不发散。

端到端测试在真实浏览器里：拖出方块、画闭合形状和线、选材料和固定、点圆和拖圆、钉子摆动、马达转动和在属性面板里改方向、弹簧、绳子、用橡皮剪断绳子、撤销重做和快捷键、运行时拖拽物体、时光倒流、分享链接在新页面打开后场景相同、刷新后画布还在、演示场景、**浏览器里的模拟结果和 Node 里逐位相同**（每一关的参考答案在浏览器里的结果、步数和最终状态指纹都和 Node 一致）、用鼠标画桥过第一关、失败后回到摆放状态、看答案和下一关；iPhone 尺寸下检查页面没有横向溢出、按钮够大、手指画方块、双指缩放不会画出东西、用手指过关、菜单和对话框不超出屏幕。

## 已知限制

- 没有做连续碰撞检测（求碰撞时刻），快速物体靠按速度放大的预测接触挡住：一般的甩、炸、抛都不会穿墙，但极快又极薄的东西仍可能穿过去。
- 每个凸块最多 8 个顶点；画得特别复杂的形状会被分成很多块。笔画自己交叉时只能退回到凸包。
- 很轻的物体用钉子连成长链去吊很重的东西时会被拉长（绳子工具有长度约束，不受影响）。
- 时光倒流只记录位置和速度，从过去某一刻接着播放时接触冲量从零开始，结果和原来那次不会逐位相同；“重置”是从保存的场景重建，和第一次播放完全一样。
- 逐位一致只在 Node 和 Chromium 里验证过，还没有在真机 Safari 上实际比对（引擎只用了规范规定精确结果的运算，按理应该一致）。
- 音效用 Web Audio 合成，iPhone 静音键打开时听不到。重力感应需要 HTTPS，iOS 上第一次打开会弹出授权。
