# 门道：数字电路实验台

在浏览器里搭数字逻辑电路：拖几个逻辑门、连上线、拨动开关，就能看到信号在电路里怎么走。用 React + TypeScript 写成，仿真引擎、逻辑化简、表达式综合都是自己实现的，没有用第三方电路库。电脑和手机上都能用。

## 功能

| 功能 | 说明 |
| --- | --- |
| 元件 | 输入/输出引脚、按钮、时钟、常量、指示灯（5 种颜色）、十六进制显示、七段数码管；与、或、非、异或、与非、或非、同或、缓冲器（多输入门可设 2–8 个输入）；三态门、二选一数据选择器；D、JK、T 触发器（上升沿触发，带异步清零）；存储：寄存器（1–8 位，带使能和清零）、ROM（地址 1–6 位、数据 1–8 位，内容在属性里用十六进制编辑）、RAM（时钟上升沿写入，属性里实时显示内容）；文字标注。 |
| 编辑 | 点击或拖动放置元件；从引脚拖到引脚连线，也可以“点一下、再点一下”连线（手机上更方便）；新导线拖到已有导线上，就接到同一个信号上。导线自动走直角，中间那段可以拖动调整，双击恢复自动。框选、拖动、旋转、复制粘贴、方向键微调、撤销/重做（200 步）。滚轮/双指缩放，拖动空白处平移。输入引脚和按钮可以绑定键盘按键。 |
| 仿真 | 五值逻辑：0、1、X（未知）、Z（高阻/悬空）、E（短路）。每个门一个单位延迟的事件驱动仿真，能表现竞争冒险的毛刺、锁存器的记忆、环形振荡器。电路停不下来时会提示，并把一直在变的导线标出来。运行/暂停、单拍、1–2048 拍/秒、复位。 |
| 逐级传播 | 打开后信号一级一级地穿过门电路，能亲眼看到毛刺是怎么出现的；波形图同步记录每一级。 |
| 自定义芯片 | 把电路封装成芯片：芯片内部的输入/输出引脚就是它的接口。芯片里可以再放芯片（会检查不能递归），修改芯片内部，所有用到它的地方立即更新。双击芯片进入内部，内部也可以单独仿真。**选中一部分电路按 Ctrl+G**，选中的逻辑会移进新芯片，跨出选区的连线自动变成芯片引脚（同一个外部信号只占一个输入，同一个内部输出只占一个输出，引脚以相连的开关/输出命名），原位置换成芯片并接好线。 |
| 真值表 | 自动对所有输入组合仿真生成真值表（最多 10 个输入），给出最简与或式、最简或与式（Quine–McCluskey），2–4 个输入时画卡诺图，鼠标移到某一项上会标出它覆盖的格子。可以一键用最简式重新生成一个芯片。含锁存器/触发器的电路会注明。 |
| 状态图 | 含触发器和时钟的电路，自动推算状态转移表（现态 + 输入 → 一个时钟周期后的次态 + 输出，最多 6 个触发器、4 个输入），画出状态图，标出从复位状态能到达哪些状态，区分摩尔型/米利型。仿真运行时，状态图高亮当前状态。 |
| 自动生成电路 | 两种方式：写表达式，如 `S = A ^ B ^ Cin`、`Cout = A & B \| Cin & (A ^ B)`（也认 `+ · ' ¬ ⊕ and or not`）；或者直接填真值表（最多 6 个输入、8 个输出，格子可以填 0、1、×无关项），先化简再生成。生成的电路分层布局，相同的子表达式只生成一次，`¬(A·B)` 直接用与非门。 |
| 波形图 | 记录输入、输出、时钟、按钮、指示灯的波形；任意一根导线也可以“加入波形图”当探针。鼠标悬停看每一时刻的值。 |
| 闯关 | 17 关：从“第一根导线”、只用与非门搭非门/与门/或门/异或门，到半加器、全加器、数据选择器、四选一、三人表决、一位比较器（3 个门就够）、译码器、奇偶校验、SR 锁存器、D 锁存器、两位计数器。每关限定可用元件，点“检查”会把所有输入组合（时序电路按步骤）试一遍，并按用了几个元件给 1–3 颗星。 |
| 示例 | 半加器、4 位加法器（全加器芯片）、SR 锁存器、4 位计数器、十进制计数器 + 七段译码器（译码器芯片由化简程序自动生成）、交通灯状态机（状态转移逻辑由表达式生成）、ROM 查表显示 0–F、简易 CPU（PC + 程序 ROM + 自动生成的 ALU + 累加器寄存器，支持载入/加法/异或/空操作，可以在 ROM 里改程序）、三态总线、环形振荡器、竞争冒险。 |
| 其他 | 自动保存（包括开关的状态）；导出/导入文件；导出电路图片（SVG 或 PNG，按当前深浅色主题，适合贴进实验报告）；“复制分享链接”把整个电路压缩进网址，别人打开就能看到；深色模式；手机布局；构建后可以“添加到主屏幕”离线使用。 |

## 运行方法

需要 Node.js 22.18 或更新版本。

```bash
cd logic-lab
npm install
npm run dev          # 开发服务器，打开终端里显示的地址
npm run build        # 生成 dist/，是纯静态文件
npm run preview      # 本地预览 dist/
```

`dist/` 用的是相对路径，可以原样放到任何静态托管上（GitHub Pages、对象存储、随便一个文件夹）。

## 引擎是怎么工作的

引擎在 `src/engine/`，不依赖 React 和浏览器，Node 里也能直接跑。

**网表编译**（`compile.ts`）：编辑器里的电路是“元件 + 导线”。仿真前先把它展开成扁平的网表：芯片实例递归地内联进来（芯片外部的引脚和内部的输入/输出引脚在同一个结点上），然后用并查集把导线连在一起的引脚合并成“线网”。同一个芯片定义在不同位置的实例，内部元件的路径不同（比如 `F2/x1`），状态互不干扰。直接或间接包含自己的芯片会报错。

**仿真**（`sim.ts`）：事件驱动、每个元件一个单位延迟。每一步把上一步输入发生变化的元件重新求值，再重新决议它们驱动的线网；线网的值变了，就把读它的元件排进下一步。同一步里的元件看到的是同一组线网值，所以 `A·¬A` 会出现一步宽的毛刺，交叉耦合的或非门能保持状态。一根线网上有多个驱动时按“忽略 Z、0 与 1 冲突为 E、有 X 则为 X”决议，三态总线和短路就是这么表现的。一次稳定超过 max(1000, 2×元件数) 步就判定为振荡（随电路规模放宽，几千个门串联的长链不会被误判），并记下还在变化的线网。

触发器在时钟输入从 0 变成 1 的那一步动作；修改电路后重新编译时，按元件路径把触发器状态、开关状态、时钟计数和各门的输出带到新网表里，所以边改边仿真时锁存器不会丢失状态。

**逻辑化简**（`qm.ts`）：Quine–McCluskey 求出全部质蕴涵项，先取本质质蕴涵项，再去掉被支配的项，剩下的用分支限界求精确的最小覆盖（项数最少，其次文字最少）；候选太多时退回贪心。或与式是对反函数化简再用德摩根律得到的。输出为 X/Z 的行当作无关项。

**表达式综合**（`expr.ts`）：递归下降解析（优先级 非 > 与 > 异或 > 或，支持后缀 `'`，行尾是运算符时自动续行，出错时给出行号列号和原因）。生成电路时做结构哈希，交换律下相同的子表达式共用一个门；`¬` 推到与/或/异或上变成与非/或非/同或；超过扇入上限的运算拆成树。布局按逻辑深度分列，每列按输入的平均高度排序，减少交叉。

**分析**（`analyze.ts`）：真值表逐行复位、设定输入、稳定后读输出；用 Tarjan 强连通分量找组合反馈回路（经过触发器的不算），据此提示“含锁存器”。还统计展开后的门数和最长门级路径。

**封装成芯片**（`package.ts`）：把选中的逻辑元件挪进新芯片（开关、灯、显示器留在外面），逐根检查跨出选区的导线：内侧是输入引脚的，按外侧信号源分组，每组一个芯片输入；内侧是输出引脚的，按内侧引脚分组，每组一个芯片输出。接口引脚按所连引脚的高度排列，名字取自外面相连的开关或输出引脚。测试里用它封装半加器、交叉耦合的锁存器、整个十进制计数器、以及芯片内部的一部分，封装前后的行为完全一致。

**状态转移表**（`analyze.ts` 的 `stateTable`）：把每个触发器的状态直接写进仿真器，设定输入、稳定后读输出，再让时钟走完整一个周期，读出新的触发器状态。所有“状态 × 输入”组合都试一遍，然后从全 0 状态做广度优先搜索得到可达状态。

**闯关判题**（`levels.ts`）：先检查有没有用到不允许的元件，组合逻辑关把所有输入组合都试一遍，时序关按预先写好的步骤一步步设置输入、检查输出；振荡的电路直接判错，不会卡住。

## 代码结构

```
src/
  engine/              纯 TypeScript，无 DOM 依赖
    types.ts           文档模型：元件、导线、电路、项目
    values.ts          五值逻辑和线网决议
    parts.ts           每种元件的尺寸、引脚、旋转
    compile.ts         展开芯片、并查集求线网
    sim.ts             事件驱动仿真
    analyze.ts         真值表、反馈回路、统计
    qm.ts              Quine–McCluskey 化简
    expr.ts            表达式解析与电路综合
    geometry.ts        导线直角走线
    levels.ts          关卡与判题
    package.ts         把选中的元件封装成芯片
    examples.ts        示例电路
    serialize.ts       项目文件校验、分享链接（deflate + base64url）
    builder.ts         用代码搭电路的小工具
  store/
    store.ts           编辑器状态、撤销重做、剪贴板、芯片管理、本地保存
    simctl.ts          把仿真和编辑器接起来：增量重编译、时钟循环、逐级动画、波形记录
  ui/                  React 组件：画布、元件面板、属性、真值表、芯片、关卡、波形、对话框
  App.tsx, main.tsx, styles.css
tests/
  unit/                Node 自带测试运行器直接跑 TypeScript
  e2e/                 Playwright（电脑 + iPhone 13 尺寸）
```

## 已知限制

- 只有 1 位宽的导线，没有总线/分线器；多位数据（包括寄存器、ROM、RAM 的每一位）要用多根线。
- 每个门的延迟都一样，没有可调的传播延迟，也不模拟建立/保持时间。
- 真值表最多 10 个输入，化简最多 8 个输入。
- 布线是自动直角线，只能调整中间一段，不做避障。
